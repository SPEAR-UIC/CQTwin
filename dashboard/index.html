Native PoliciesAll 20 built-in heuristics are available directly in __PROJECT_NAME__ (no formula needed). Notation: w=wait, t=requested walltime, n=requested procs, N=total procs; the highest-priority job dispatches first.
  • `fcfs` — earliest submit first
  • `lcfs` — latest submit first
  • `sjf` / `ljf` — shortest / longest requested walltime t
  • `srf` / `lrf` — fewest / most requested processors n
  • `scf` / `lcf` — smallest / largest resource–time product t·n
  • `wfp1` / `wfp2` / `wfp3` — weighted wait-to-walltime: linear w/t, quadratic (w/t)²·n, cubic (w/t)³·n
  • `sww` — size-weighted wait (w/t)·n
  • `fcsj` — size-normalized wait w/(t·n) (favors small jobs)
  • `fat` — size-aware weighted wait (w/t)·(n/N)³
  • `unicep` — wait ÷ processor fraction w/(log₂(n/N)·t)
  • `f1`–`f4` — learned composite priority functions
  • `bsld` — bounded slowdown (w+t)/max(t,τ), τ=1h (clamped ≥1)

Online Advisory CQTwin

The committed schedule is byte-identical to an offline run of that policy; the projections are advisory only.

ItemMeaning / What it does
RunSelects the completed CQTwin run whose state you want to replay from a snapshot.
Search / Page / Page SizeFilters and pages through available historical runs.
Snapshot Mode / Snapshot TimeChooses where to freeze the run. Percent mode uses the run makespan; absolute mode uses simulation seconds.
Fork PolicyAlternative scheduling policy used for the what-if branch.
Backfill / Window SizeForked scheduling controls for the what-if branch.
Horizon (hours)How far forward to project the queue state from the selected snapshot.
Downtime (hours)Duration used by the downtime advisor and planned maintenance what-if.
Planned Downtime Offset / NoticeInjects a simulated maintenance window relative to the snapshot and shows its effect on waits and queue depth.
Force Job IDOptional manual pin for a queued job. In the UI, clicking a queue row sets and runs this automatically.
Save ForkSaves the current Snap Shot scenario, including selected run, snapshot, fork policy, pinned job, and results.
Open Fork In New TabSaves the current scenario and opens it in a new tab for side-by-side counterfactual exploration.
Clear Force JobRemoves the current pinned-job what-if and reruns the plain fork scenario.
Evaluate SnapshotReplays from the selected snapshot and updates all baseline, fork, and downtime outputs.
Saved Forks / Load Saved ForkReloads a previously saved scenario branch.
Snapshot SummaryCurrent state at the frozen time: queued jobs, running jobs, future arrivals, free processors, and next completion.
Current State tablesRunning jobs and queued jobs at the snapshot under the original run state.
